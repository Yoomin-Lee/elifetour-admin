## 1. 드롭다운 UI 전수 통일

### 배경

사이트 전체에서 일부 `<select>` / `<Select>` 요소가 브라우저 기본 화살표(↕)를 그대로 표시하여 페이지 디자인과 불일치.  
이전에 일부만 수정했으나 누락된 파일이 다수 존재. 이번에 전수 점검·통일.

### 통일 패턴

```tsx
<div className="relative">
  <Select ... className="... appearance-none pr-7">
    {/* options */}
  </Select>
  <ChevronDown className="pointer-events-none absolute right-2 top-1/2 -translate-y-1/2 h-3.5 w-3.5 text-slate-400" />
</div>
```

### 2-2. 캐빈등급 드롭다운 추가 (메인 편집 폼)

기존 메인 편집 폼에는 캐빈등급 필드 없음(GradesPanel 확장 패널에서만 편집 가능).  
PDF에서 실제 사용된 등급 코드 추출 → 선택 가능한 SelectOrInput으로 추가.

```ts
const CABIN_GRADES = ['4D', '2D', 'BA2', 'BR1', 'BM1', 'VD', '4U', '3D', '1D', 'VC']
```

- 직접입력(✏ 직접입력) 옵션도 제공 (SelectOrInput 패턴 재사용)
- 저장 시 `cabin_grades` 테이블에 upsert — 기존 등급 존재 시 grade 코드만 갱신, 없으면 신규 생성

```ts
mutationFn: async (id: string) => {
  await updateVoyage(id, { ... })
  if (editForm.cabin_grade) {
    const existing = gradeMap[id]?.[0]
    if (existing) {
      await saveCabinGrades(id, [{ id: existing.id, grade: editForm.cabin_grade, ...existing }], [])
    } else {
      await saveCabinGrades(id, [{ grade: editForm.cabin_grade, total: 0, reserved: 0, ... }], [])
    }
  }
}
```

### 2-3. 캐빈가 컬럼 복원 + 테이블 레이아웃 고정

보유캐빈/예약캐빈/잔여캐빈 컬럼 폭 확대 후 캐빈가 컬럼이 화면 밖으로 밀려나는 문제 수정.

- 보유캐빈/예약캐빈/잔여캐빈: `w-20 px-3` → `w-16 px-2` (좁힘, whitespace-nowrap 유지)
- `table-fixed` 추가 — 브라우저 컬럼 폭 재분배 방지, 지정된 `w-*` 값 강제 적용
- 캐빈가 컬럼(`w-24`) 항상 표시 보장

### 2-4. 편집 폼 레이아웃 6열로 확장

5개 필드 → 6개 필드(캐빈등급 추가)에 맞춰 그리드 변경.

```tsx
<div className="grid grid-cols-2 gap-2 sm:grid-cols-3 lg:grid-cols-6 mb-2">
  {/* 선사 | 크루즈명 | 에이전트 | 캐빈등급 | 보유캐빈 | 잔여캐빈 */}
</div>
```

## 3. 지상 탭 — 입항·출항 TimePicker 적용

### 배경

ShoreTab 편집 폼에서 입항·출항 시간이 `<Input type="time">` (브라우저 네이티브 시간 입력)으로 표시.  
DatePicker와 같은 커스텀 피커 계열이 아닌 네이티브 UI라 디자인 불일치.

### 변경

- `<Input type="time">` → `<TimePicker size="sm">` 로 교체
- `size="sm"`: 높이 28px, 텍스트 xs 크기 — 편집 폼 내 다른 필드와 균일
- onChange 핸들러: `set('arrival_time')` (이벤트 기반) → `v => setForm(prev => ({ ...prev, arrival_time: v }))` (문자열 직접)
