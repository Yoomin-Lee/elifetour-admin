## 4. 취소료 보기 모드 — 컬럼 변경 및 날짜 범위 표시

**파일:** `src/components/voyages/CancellationCard.tsx`

### 컬럼 변경
| 이전 | 이후 |
|------|------|
| 구분 | 구분 |
| 기간 (D-90 ~ D-61) | 기간 (D-90 ~ D-61) |
| 취소료 | **날짜** (실제 날짜 범위) |
| 통화 | **취소료** |
| — | ~~통화 제거~~ |

### 날짜 컬럼 상세
- **목적**: D-마이너스 숫자만으로는 실제 적용 구간을 직관적으로 파악하기 어려워, 실제 날짜 범위(`MM.DD ~ MM.DD`)로 변환하여 표시
- **기준일 산출 우선순위**:
  1. `reference_date` (행별 직접 지정)
  2. 크루즈 카테고리 + `boardingDate` 존재 시 → 탑승일
  3. 나머지 → 출발일(`departureDate`)
- **변환 함수**: `dMinusToDate(refDate, dMinus)` — 기준일에서 D-n일 뺀 날짜를 `MM.DD` 포맷으로 반환
- `reference_date` 직접 지정 행에는 **"지정"** 뱃지 표시 (brand 색상)
- D-minus가 null(무제한)인 경우 `~` 표시
