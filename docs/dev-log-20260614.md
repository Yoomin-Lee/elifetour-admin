### 1. 항공 비행시간 자동 계산 유틸 구현 (date-fns-tz + DST)

**배경**  
서머타임(DST)이 있는 구간(미국 서부, 유럽 등)에서 비행시간이 현지 시계 기준으로 계산되어 오차가 발생하는 문제를 해결하기 위해, `date-fns-tz`를 활용한 UTC 기반 비행시간 계산 로직을 구현함.

**신규 파일**

| 파일 | 설명 |
|------|------|
| `src/lib/utils/flightCalc.ts` | 공항 IATA → IANA 타임존 맵, DST 반영 비행시간 계산 유틸 |
| `src/lib/queries/voyageFlights.ts` | Supabase CRUD (voyage_flights 테이블) |
| `src/hooks/useFlightCalc.ts` | React 실시간 비행시간 계산 훅 |

**핵심 로직 (`flightCalc.ts`)**
- `fromZonedTime(localDatetimeStr, ianaTimezone)` — 현지 시각을 UTC로 변환 (DST 자동 반영)
- `differenceInMinutes(arrUtc, depUtc)` — UTC 기준 비행시간(분) 계산
- `formatInTimeZone(utcDate, tz, format)` — UTC → 현지 오프셋 포함 ISO 문자열
- 지원 공항 30개: ICN, SIN, DXB, LAX, SEA, FCO, VCE, MUC, BCN, DOH, IST, HKG, PVG, NRT, ATL, FLL 등

**타입 인터페이스**
```typescript
FlightCalculationParams {
  departureAirport: string   // IATA 코드
  arrivalAirport: string
  departureDate: string      // 'YYYY-MM-DD' 또는 'YY/MM/DD'
  departureTime: string      // 'HH:MM'
  arrivalDate: string
  arrivalTime: string
}
FlightCalculationResult {
  depDatetime: Date; arrDatetime: Date
  depIso: string; arrIso: string   // 오프셋 포함 ISO (e.g. 2026-12-15T14:35:00+09:00)
  depTimezone: string; arrTimezone: string
  durationMinutes: number
  durationText: string   // e.g. "13시간 25분"
}
```

## 트러블슈팅

| 문제 | 원인 | 해결 |
|------|------|------|
| 한글 깨짐 | PowerShell `Get-Content`가 시스템 인코딩(CP949) 사용 | `[System.IO.File]::ReadAllText($path, UTF8)` 사용 |
| `Invoke-WebRequest` 실패 | NonInteractive 모드에서 동작 안 함 | `Invoke-RestMethod`로 교체 |
| `column is of type date but expression is of type text` | UNION ALL의 첫 행에 명시적 타입 캐스트 누락 | `'2025-02-13'::date`, `'percent'::fee_type` 등 첫 행에 캐스트 추가 |
| `more than one row returned by subquery` | voyages 테이블에 중복 행 존재 | CTE + ORDER BY created_at DESC LIMIT 1으로 중복 제거 |
| `function max(uuid) does not exist` | UUID 타입에 MAX() 함수 없음 | `ORDER BY created_at DESC LIMIT 1` 방식으로 우회 |
