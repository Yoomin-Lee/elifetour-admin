## 변경 사항

### 1. 새 행사 등록 sort_order 버그 수정 (`src/lib/queries/voyages.ts`)

**문제**  
`createVoyageWithChildren`에서 flights, itinerary, policies를 저장할 때 `sort_order: p.sort_order || i + 1` 패턴 사용. 드래그로 순서를 변경해도 항목 내부의 `sort_order` 값은 이전 값을 유지하기 때문에, 드래그 결과가 DB에 반영되지 않음.

예: preset에서 불러온 policies의 `sort_order`가 `[1, 2, 3]`일 때 2번을 0번으로 드래그하면 배열 순서는 `[2, 1, 3]`이지만, `sort_order` 값은 여전히 `[2, 1, 3]`이 아닌 원본 `[2, 1, 3]` → DB 저장 시 `sort_order`로 정렬하면 다시 `[1, 2, 3]` 순서로 복원됨.

**수정**
```ts
// 변경 전
flights.map((f, i) => ({ ...f, voyage_id: id, sort_order: f.sort_order || i + 1 }))

// 변경 후 — 항상 현재 배열 인덱스 기준
flights.map((f, i) => ({ ...f, voyage_id: id, sort_order: i + 1 }))
```
flights, itinerary_days, cancellation_policies 세 테이블 모두 동일하게 적용.

### 2. 지역/항공사 드롭다운 클릭 빈도순 정렬

**신규 마이그레이션**
- `20260624000002_usage_count.sql`: `region_options`, `airline_options`에 `usage_count INTEGER DEFAULT 0` 컬럼 추가
- `20260624000003_backfill_usage_count.sql`: 기존 행사 데이터 기준 usage_count 백필

**백필 쿼리 방식**
```sql
-- 지역: voyages.region 집계
UPDATE region_options ro SET usage_count = sub.cnt
FROM (SELECT region AS label, COUNT(*) AS cnt FROM voyages GROUP BY region) sub
WHERE ro.label = sub.label;

-- 항공사: voyages.airline + airline_return 합산
UPDATE airline_options ao SET usage_count = sub.cnt
FROM (
  SELECT label, SUM(cnt) AS cnt FROM (
    SELECT airline AS label, COUNT(*) AS cnt FROM voyages GROUP BY airline
    UNION ALL
    SELECT airline_return AS label, COUNT(*) AS cnt FROM voyages GROUP BY airline_return
  ) combined GROUP BY label
) sub WHERE ao.label = sub.label;
```

**RPC 함수 (race condition 방지)**
```sql
CREATE OR REPLACE FUNCTION increment_region_usage(row_id UUID)
RETURNS VOID LANGUAGE SQL SECURITY DEFINER AS $$
  UPDATE region_options SET usage_count = usage_count + 1 WHERE id = row_id;
$$;
```
`UPDATE ... SET count = count + 1` 서버 사이드 실행 → 동시 클릭 시 카운트 유실 없음.

**쿼리 정렬 변경**
```ts
// 변경 전
.order('sort_order')

// 변경 후
.order('usage_count', { ascending: false })
.order('sort_order')  // usage_count 동점 시 fallback
```

**BasicInfoSection.tsx 변경**
- `select: data => data.map(r => r.label)` 제거 → 전체 객체(`id` 포함) 유지
- `trackRegion(label)` / `trackAirline(label)`: 드롭다운에서 선택 시 id로 RPC 호출 (직접 타이핑은 해당 없음)
- `stripParens` 적용 후 label 매칭으로 항공사 id 조회

## 기술 메모

- **`usage_count` 동점 시 fallback**: Supabase `.order()` 체이닝으로 1차 `usage_count DESC`, 2차 `sort_order ASC` 정렬. 아직 사용 기록 없는 신규 옵션은 `sort_order` 기준으로 배치됨.
- **Tailwind arbitrary grid columns**: `sm:grid-cols-[88px_1fr_78px_78px]` 형식으로 CSS `grid-template-columns`를 임의값으로 지정 가능. 뷰포트 640px 이상에서 적용.
- `tsc --noEmit` → 오류 없음
- 배포: GitHub Actions 자동 (main push)
