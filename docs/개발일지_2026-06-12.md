# 개발일지 — 2026-06-12

## 프로젝트 개요
- **프로젝트명**: elifetour-admin (이라이프투어 직원 관리 시스템)

- **참고 템플릿**: yoomin-lee/templete03 (React + Vite + Supabase), aebonlee/rest03 (Tailwind)

## Phase 1 개발 완료

### 기술 스택
| 항목 | 선택 | 이유 |
|---|---|---|
| Frontend | React 19 + Vite 7 | 템플릿 기반, 빠른 개발 |
| Styling | Tailwind CSS 3 | 관리 도구 UI에 최적, 반응형 구현 효율적 |
| Backend/DB | Supabase (PostgreSQL) | 인증·실시간·스토리지 통합, 무료 티어 |
| 인증 | Google OAuth | 직원 Google 계정 활용 |
| 라우팅 | React Router 7 | 클라이언트 SPA 라우팅 |
| 배포 | GitHub Pages + Actions | 무료, 자동배포 |

### 구현된 화면
1. **로그인 페이지** (`/login`)
   - Google OAuth 로그인 버튼
   - 브랜드 디자인, 모바일 대응
   
2. **대시보드** (`/`)
   - 예정 여행 수, 진행중 여행 수, 전체 여행 수, 이번달 신규 여행자 수 통계 카드
   - 예정 여행 최근 5건 미리보기

3. **여행 일정 목록** (`/trips`)
   - 여행명 검색, 상태 필터
   - 카드형 레이아웃 (반응형 그리드)
   - 여행 등록 모달 (TripForm)
   - 여행 삭제 (hover 시 표시)

4. **여행 상세/명단** (`/trips/:id`)
   - 여행 정보 카드 (수정/삭제)
   - 여행자 명단 테이블 (데스크탑) / 카드 (모바일)
   - 여행자 추가/수정/삭제
   - 이름·연락처·여권번호 인라인 검색
   - CSV 내보내기 (BOM 포함, 한글 엑셀 호환)

5. **여행자 전체 검색** (`/passengers`)
   - 이름·연락처·여권번호로 전체 명단 검색
   - 해당 여행 바로가기 링크

### 데이터베이스 스키마
```
eli_profiles   - 직원 프로필 (auth.users 확장)
eli_trips      - 여행 일정 (제목, 목적지, 출발/귀국일, 상태, 담당자, 메모)
eli_passengers - 여행자 명단 (여권정보, 결제상태, 객실타입, 특이사항)
```
- RLS 적용: 로그인한 직원 전원 읽기/쓰기 가능
- `updated_at` 자동 갱신 트리거

### 모바일 대응
- 사이드바: 모바일에서 햄버거 메뉴로 접기/펼치기
- 여행자 명단: 데스크탑 테이블 ↔ 모바일 카드 레이아웃 자동 전환
- PWA-like 메타태그 (홈 화면 추가 지원)
