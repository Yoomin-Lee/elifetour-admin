### 4. CalendarTab.tsx 주요 구현

#### 데이터 연동

```ts
const { data: voyages = [], isLoading } = useQuery({
  queryKey: ['voyages'],
  queryFn: fetchVoyages,
})
```

기존 항차 탭들과 동일한 React Query 캐시 키(`['voyages']`)를 공유.
항차검색 탭에서 이미 데이터를 받아뒀다면 네트워크 요청 없이 재사용.

#### 달력 그리드

`date-fns`의 `startOfWeek` / `endOfWeek` / `eachDayOfInterval`로 6×7 셀 구성.
각 셀에서 `isWithinInterval(day, { start: depart, end: return })` 로 해당일 포함 행사 필터.

최대 3개 표시, 초과 시 "+N개 더" 텍스트.

#### 상태별 색상

| 상태 | 색상 |
|------|------|
| 미오픈 | 회색 |
| 판매중 | 파랑 |
| 마감 | 주황 |
| 출발완료 | 초록 |
| 취소 | 빨강 + 취소선 |

`VoyageStatus` 타입을 키로 사용하여 누락 케이스 컴파일 시 감지.

#### 행사 클릭 동작

```ts
const goToVoyage = (id: string) =>
  navigate(`/voyages?tab=항차검색&voyage=${id}`)
```

달력에서 행사 클릭 → 항차검색 탭의 해당 행사 상세로 바로 이동.

#### 하단 패널

- **범례**: 상태별 색상 + 출/귀 마크 설명
- **이번 달 출발 행사 목록**: 출발일 오름차순 정렬, 클릭 시 항차 상세 이동
