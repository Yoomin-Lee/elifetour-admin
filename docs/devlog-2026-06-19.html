Layer 1 — PostgreSQL TIME 포맷 파싱 오류
src/lib/utils/flightCalc.ts

PostgreSQL TIME 컬럼이 "HH:MM:SS"를 반환하는데, calcFlightDuration이 "2026-06-15T10:50:00:00"처럼 잘못된 ISO 문자열을 생성 → fromZonedTime이 throw → 계산 불가.

/** 'HH:MM:SS' 또는 'HH:MM' → 'HH:MM' */
function normalizeTime(raw: string): string {
  return raw.slice(0, 5)   // "10:50:00" → "10:50"
}
