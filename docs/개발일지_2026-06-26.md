## 작업 요약

### 1. 항공 편명 자동 포커스 (FlightsCard · FlightsEditor)

**문제:** 편명/날짜/시각 상세 구간 추가 시 "소요 시간" 필드에 포커스가 잡히는 현상 반복 발생

**원인 분석:**
- `useFieldArray.append()`의 기본값 `shouldFocus: true`가 RHF 내부적으로 마지막 등록 필드를 포커스
- `useEffect + ref` 패턴이 RHF의 자동 포커스에 덮어씌워지는 타이밍 충돌

**해결 (FlightsEditor):**
- `appendSeg(EMPTY_SEGMENT, { shouldFocus: false })` — RHF 자동 포커스 비활성화
- `useEffect` 내 `setTimeout(fn, 0)` — 다음 틱으로 포커스 지연, 타이밍 충돌 방지
- grid wrapper `ref` + `querySelector('input')` — 첫 번째 input(편명) 직접 포커스

**해결 (FlightsCard):**
- `SegmentDraftRow`에 `autoFocus` prop 추가
- 토글 열 때: `focusTarget = 0` (첫 번째 구간 편명 포커스)
- 구간 추가 시: `focusTarget = r.segments.length` (새 구간 편명 포커스)
- `useEffect(() => { if (autoFocus) ref.current?.focus() }, [])` 마운트 시 1회 실행

### 2. 항공 구간 보기 모드 소요시간 줄바꿈 제거 (FlightsCard)

**문제:** 꺾쇠 펼침 시 소요시간 텍스트가 두 번째 줄로 밀림

**원인:** `flex flex-wrap gap-x-3` — 아이템 수가 많아 overflow 시 줄바꿈

**해결:**
- `flex-wrap` 제거, `gap-x-1.5`로 간격 축소
- `whitespace-nowrap` + `shrink-0` 적용
- 출발 날짜·시각, 도착 날짜·시각을 각각 단일 `<span>`으로 통합

### 5. 직원(staff) 권한 열람 전용 전환

**변경 범위:**

| 레이어 | 내용 |
|--------|------|
| UI | `AuthContext.tsx` — `canWrite = !isEscort` → `canWrite = isAdmin` |
| DB | `20260626000000_staff_readonly.sql` — 15개 테이블 write RLS 정책 admin 전용으로 교체 |

**역할별 권한:**
- `admin` (관리자): 모든 수정·편집·삭제 가능 — 기존과 동일
- `staff` (직원): 열람(SELECT)만 가능, 편집 UI 노출 없음
- `escort` (인솔자): 기존과 동일 (열람 전용)

**추가 보호:**
- DB 트리거 `eli_guard_role_change()`: 비관리자의 role 셀프 변경 차단 (기존 트리거 유지)
- `/users` 페이지: `RoleRoute(['admin'])` — staff 접근 불가

**마이그레이션 특이사항:**
- 초기 버전에서 `partners` 테이블 미존재로 오류 발생
- `DO $$ BEGIN ... IF EXISTS ... END $$` 블록으로 테이블 존재 여부 체크 후 재배포
