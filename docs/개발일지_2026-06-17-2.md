### 1. MN 탭 — 소프트 삭제(Soft Delete) + 복원 기능

#### 배경
MN 섹션을 실수로 삭제했을 때 되돌릴 방법이 없었음.

#### DB 변경
Migration `supabase/migrations/20260617000001_mn_sections_soft_delete.sql`:
- `mn_sections` 테이블에 `deleted_at timestamptz` 컬럼 추가
- `WHERE NOT EXISTS` 조건으로 원본 11개 섹션 안전하게 재삽입 (중복 없이 복구)

#### 쿼리 변경 (`src/lib/queries/mnSections.ts`)
- `fetchMnSections`: `.is('deleted_at', null)` — 삭제 항목 숨김
- `fetchDeletedMnSections`: `.not('deleted_at', 'is', null)` — 삭제 항목만 조회
- `softDeleteMnSection(id)`: `deleted_at = now()` 업데이트
- `restoreMnSection(id)`: `deleted_at = null` 복원
- `hardDeleteMnSection(id)`: 영구 삭제

#### UI (`src/components/voyages/tabs/MNTab.tsx`)
- 삭제 버튼 클릭 → `DeleteConfirmModal` (AlertTriangle 아이콘, 백드롭 블러)
- MN 탭 하단 "삭제된 항목 (N)" 접이식 패널: 복원 / 영구삭제 버튼
- 영구삭제 시 이중 확인 모달

### 3. 중복 행사 삭제

27/10/16 동부 지중해 행사 복제 실수로 2건 생성됨.  
Supabase SQL Editor에서 ROW_NUMBER 방식으로 중복 1건 삭제:

```sql
DELETE FROM voyages WHERE id IN (
  SELECT id FROM (
    SELECT id, ROW_NUMBER() OVER (PARTITION BY departure_date, region ORDER BY created_at ASC) AS rn
    FROM voyages WHERE departure_date::text LIKE '2027-10%'
  ) ranked WHERE rn > 1
);
```
