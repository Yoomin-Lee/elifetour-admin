### 1. '유류할증' → '유류세' 표기 변경

"항차조회 > 항공에서 '유류할증'이라는 단어를 '유류세'로 바꿔달라, 홈페이지 전체에 있는 단어를 다 바꿔달라"는 요청.

`src/` 전체에서 `유류할증`을 검색해 화면에 노출되는 5개 파일을 확인:
- `FlightsCard.tsx` — 항공료 수식 라벨, 상세 카드 표시
- `FlightsEditor.tsx` — 항공료 입력 폼 라벨
- `FlightsTab.tsx` — 항공료 수식 라벨(편집/조회 두 군데 + 요약 표시)
- `InventoryTab.tsx` — 보유현황 테이블 헤더
- `excel.ts` — 항공좌석 관련 엑셀 내보내기 컬럼 헤더 4곳

DB 컬럼명(`fare_fuel`)은 내부 식별자라 그대로 두고, 사용자에게 노출되는 라벨 문자열만 `유류세`로 교체. `docs/`·`supabase/migrations/`의 과거 기록·SQL 주석은 "홈페이지에 있는" 표기가 아니므로 그대로 둠.

1차 작업에서 `FlightsTab.tsx`는 원래 `유류할증료`(뒤에 "료"가 붙은 표기)로 쓰이고 있어 단순 치환 시 `유류세료`가 됐는데, 확인 결과 다른 화면들처럼 "료" 없이 `유류세`로 통일해달라는 후속 요청을 받아 3곳 모두 다시 수정.
