### 1. 대시보드 통계 요약 카드 — 높이 정렬

대시보드 상단 통계 카드들의 높이가 서로 달랐던 문제. "이번달 결제 마감" 카드에만 연체 건수가 있을 때 "연체 N건" 보조 텍스트가 붙어서 그 카드만 세로로 길어지고, 나머지 카드와 줄이 안 맞았음.

- `index.css`에 `--stat-card-min-h: 6.75rem` 공통 변수와 이를 참조하는 `.stat-card` 컴포넌트 클래스 추가. 보조 텍스트가 있는 카드 기준으로 높이를 잡아, 값 유무와 상관없이 모든 카드가 동일한 최소 높이를 갖도록 함.
- `StatCard`의 보조 텍스트(`sub`)를 조건부 렌더링하지 않고 항상 렌더링하도록 변경. 값이 없을 때는 `invisible` 클래스로 감추되 `h-4` 고정 높이 슬롯은 그대로 차지해, 텍스트가 나타나도 레이아웃이 밀리지 않게 함.
- 카드 그리드 컨테이너에 `items-stretch`를 적용하고, 드래그 가능한 카드 wrapper·`Link`·`.stat-card`까지 `h-full`을 전파해 한 행 안의 카드들이 실제로 같은 높이로 늘어나도록 함.
- 텍스트 블록을 `flex flex-col justify-center`로 감싸 아이콘·라벨·숫자·보조텍스트의 세로 위치가 카드마다 동일하게 오도록 정리. 카드 좌우 너비·간격은 변경하지 않음.
- 편집 모드의 "카드 추가" 플레이스홀더 버튼도 하드코딩된 `min-h-[80px]` 대신 동일한 `--stat-card-min-h` 변수를 참조하도록 맞춤.

배포 후 라이브 CSS 번들(`elifeetis.com`)을 직접 받아 `--stat-card-min-h`와 `.stat-card` 규칙이 실제로 반영됐는지 확인. 대시보드 자체는 구글 로그인 뒤에 있어 로그인한 화면을 직접 캡처해 보진 못함.
