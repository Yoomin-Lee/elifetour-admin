## 1. 대시보드 항차 데이터 통합

### 배경

기존 대시보드는 `eli_trips` 기반의 여행 일정 통계만 표시.  
항차 관리(VoyageMaster)가 TS 기반으로 별도 구현되어 있었으나 대시보드(JS)에서 항차 데이터를 활용하지 못하고 있었음.  
Vite 환경에서 JS → TS import가 가능하므로 기술적 장벽 없이 통합 가능.

### 추가된 쿼리 함수

`src/lib/queries/voyages.ts`에 `fetchVoyageDashboardData()` 신규 추가.

```typescript
export interface VoyageDashboardData {
  onSaleVoyages: OnSaleVoyage[]          // 판매중 항차 목록
  thisMonthDepartures: DepartureVoyage[] // 이번달 출발 항차
  thisMonthPayments: PaymentRow[]        // 이번달 미완료 결제 마감
}
```

- **판매중 항차**: `status = '판매중'`인 항차 전체, 출발일 오름차순
- **이번달 출발**: 당월 1일~말일 출발, 취소 제외
- **이번달 결제 마감**: `payment_schedules` 당월 `due_date` + `is_completed = false`, `voyages(region, departure_date)` 조인

## 2. 대시보드 전면 개편

### 변경 전 → 후

| 항목 | 변경 전 | 변경 후 |
|------|---------|---------|
| 통계 카드 | 예정 여행 / 진행중 여행 / 전체 여행 / 이번달 신규 여행자 | 판매중 항차 / 총 예약 인원 / 이번달 출발 / 이번달 결제 마감 |
| 메인 섹션 | 예정 여행 5건 목록 | 판매중 항차 현황 테이블 |
| 하단 섹션 | 없음 | 이번달 결제 마감 + 이번달 출발 항차 |

### 통계 카드 상세

| 카드 | 색상 | 데이터 | 비고 |
|------|------|--------|------|
| 판매중 항차 | 보라 | `onSaleVoyages.length` | |
| 총 예약 인원 | 파랑 | 판매중 항차 `customer_count` 합산 | |
| 이번달 출발 | 청록 | `thisMonthDepartures.length` | |
| 이번달 결제 마감 | 주황 / 빨강 | `thisMonthPayments.length` | 연체 건수 있으면 빨강 + "연체 N건" 서브텍스트 |

### 판매중 항차 현황 테이블

- 컬럼: 지역 / 선박 / 출발일 / 예약인원 / 잔여 캐빈
- 잔여 캐빈 색상 규칙:
  - `>20%` → 초록
  - `1~20%` → 주황
  - `0석` → 빨강 "마감"

### 연결 링크

| 위치 | 링크 | 이동 대상 |
|------|------|----------|
| 이번달 결제 마감 | "결제 탭 →" | `/voyages?tab=결제` |
| 이번달 출발 항차 | "달력 보기 →" | `/voyages?tab=달력` |

VoyageMaster는 `useSearchParams`로 `tab` 파라미터를 읽으므로 URL 직접 연결 가능.

### 데이터 로딩 개선

기존 `Promise.all` → `fetchVoyageDashboardData()` 단일 호출로 변경.  
항차 API 실패 시 `.catch(() => {})` 처리로 빈 상태 유지, 화면 깨짐 없음.

## 3. 탭 패널 레이아웃 개선

### 배경

판매중 항차 현황 테이블이 전체 너비를 차지해 이번달 결제 마감·출발 항차가 화면 하단으로 밀려 가시성이 낮았음.

### 변경 내용

하단 3개 섹션(판매중 항차 현황 / 이번달 결제 마감 / 이번달 출발 항차)을 **하나의 탭 패널**로 통합.

```
[판매중 항차 현황] [이번달 결제 마감 ❶] [이번달 출발 항차]
───────────────────────────────────────────────────────
  선택된 탭 콘텐츠
```

- 탭 클릭으로 전환, 3개 섹션이 동일 공간 공유
- 연체 결제가 있으면 "이번달 결제 마감" 탭 헤더에 빨간 숫자 뱃지 표시
- 기본 활성 탭: 판매중 항차 현황
