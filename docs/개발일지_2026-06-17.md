# 개발일지 — 2026-06-17

## 진행 내용

### 연도 필터 드롭다운 전면 적용 + 상태 드롭다운 UI 통일

---

### 1. 배경 및 목적

이전까지 CruiseTab(크루즈)에만 연도 필터가 존재하고, 나머지 탭은 텍스트 검색만 제공되어 연도별 조회가 불편했음.  
또한 크루즈 탭의 연도 선택 UI가 브라우저 기본 `<select>` 요소라 사이트 디자인과 불일치.  
새 행사 등록 폼의 `상태` 필드도 동일한 문제가 있었음.

---

### 2. 공통 컴포넌트 신규 제작

#### `src/components/ui/year-select.tsx` — 연도 선택 드롭다운

- 버튼 트리거 + 절대 위치 팝오버 방식 (DatePicker·TimePicker와 동일 패턴)
- 브랜드 컬러(`#0F4C8A`) 포커스 링, hover 시 `bg-brand/5` 배경
- 선택된 연도 bold + brand 색 강조
- `전체 연도` 옵션 포함, 기본값은 현재 연도

#### `src/components/ui/field-select.tsx` — 폼 필드용 커스텀 선택 드롭다운

- `string[]` 또는 `{value, label}[]` 형태 옵션 모두 지원
- 선택된 항목에 체크마크(✓) 표시
- `Controller` 와 함께 사용하는 react-hook-form 친화적 설계

---

### 3. 전체 탭 연도 필터 적용

| 탭 | 변경 전 | 변경 후 |
|---|---|---|
| 항차검색 (VoyageSearch) | 네이티브 `<select>` | `<YearSelect>` |
| 상품등록 (ProductTab) | 없음 | `<YearSelect>` 추가 |
| 크루즈 (CruiseTab) | 네이티브 `<select>` | `<YearSelect>` |
| 항공 (FlightsTab) | 없음 | `<YearSelect>` 추가 |
| 호텔 (HotelTab) | 없음 | `<YearSelect>` 추가 |
| 취소료 (CancellationTab) | 없음 | `<YearSelect>` 추가 |
| 지상 (ShoreTab) | 없음 | `<YearSelect>` 추가 |
| 히스토리 (HistoryTab) | 없음 | `<YearSelect>` 추가 |

각 탭에서 연도 목록(`years`)은 실제 데이터에서 동적으로 추출(useMemo), 기본값은 현재 연도.  
항공·호텔·취소료·지상·히스토리는 `r.voyages?.departure_date` 기준, 상품등록·크루즈는 `v.departure_date` 기준으로 필터링.

### 4. 상태 드롭다운 UI 교체

- **`BasicInfoSection.tsx`** — `새 행사 등록 > 기본 정보 > 상태` 필드
  - `<Select {...register('status')}>` (네이티브) → `<Controller> + <FieldSelect>` (커스텀)
  - 기존 값(`미오픈`, `판매중`, `마감`, `출발완료`, `취소`) 그대로 유지
  - 폼 연동은 `Controller`의 `field.onChange` / `field.value` 사용

### 기술 노트

- `YearSelect`와 `FieldSelect` 모두 고정 위치 오버레이(`fixed inset-0 z-10`)를 backdrop으로 사용하여 외부 클릭 시 자동 닫힘
- `useMemo`로 연도 목록을 메모이제이션, 데이터 재렌더 시 불필요한 재계산 방지
- `CruiseTab`의 기존 `yearFilter` 로직(필터링, useMemo)은 유지하고 UI만 교체
