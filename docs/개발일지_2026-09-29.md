### 1. 항공 카드 '편명 · 날짜 · 시각' 구간 목록 모바일 가로 스크롤 지원

**요청:** 항차 상세 > 항공 카드의 '편명 · 날짜 · 시각' 영역에서, 모바일(iPhone Safari)로 보면 구간 정보 줄이 화면 너비를 넘어 오른쪽 끝이 잘림 (예: `1구간 OZ511 ICN → BCN 26/10/01(목) 11:5...`). 잘리는 것 자체는 괜찮지만 좌우 스와이프로도 스크롤이 되지 않아 뒤쪽 시각을 확인할 수 없는 문제. PC에서는 정상.

**원인:** `src/components/voyages/FlightsCard.tsx`의 구간 행(`div`)마다 `whitespace-nowrap overflow-hidden`이 걸려 있었음. `overflow-hidden`은 넘친 내용을 잘라낼 뿐 스크롤 영역을 만들지 않으므로, 터치 스와이프로도 잘린 부분에 접근할 수 없었음. PC에서는 화면이 넓어 넘치지 않았기 때문에 문제가 드러나지 않았음. (터치 이벤트를 막는 `touch-action`/`touch-none` 등은 해당 영역에 없음을 확인)

**수정:**
- 구간 행의 `overflow-hidden` 제거.
- 구간 목록 전체를 가로 스크롤 컨테이너로 감쌈:
  - 바깥: `overflow-x-auto overscroll-x-contain scrollbar-none [-webkit-overflow-scrolling:touch]`
  - 안쪽: `w-max min-w-full space-y-1`
- 행마다 따로 스크롤하는 대신 목록 전체를 한 번에 스크롤하도록 해, 스와이프 한 번으로 모든 구간의 시각이 같이 움직이고 구간 간 비교(정렬)가 유지되도록 함.
- 스크롤바는 같은 카드의 운임 행과 동일하게 `scrollbar-none`으로 숨김. `overscroll-x-contain`으로 끝까지 스크롤했을 때 페이지 전체가 같이 끌려가는 현상 방지.

PC에서는 내용이 폭 안에 들어오면 기존과 동일하게 보이고, 폭을 넘는 경우에만 가로 스크롤이 생김.

**검증:** `npm run build` 성공. `tsc --noEmit`에서 나오는 에러는 모두 `CancellationCard.tsx`, `FlightsEditor.tsx`의 기존 에러로 이번 변경과 무관. 실기기(iPhone Safari) 확인은 사용자 확인 필요.
