# 개발일지 2026-06-25 (9회차)

## 작업 요약
항차 마스터 > 항공 탭(FlightsTab)에 좌석 분류·항공료 분류 입력 및 조회 기능 추가. 편명 클릭으로 꺽새 자동 토글 연결.

---

## 변경 사항

### 1. 항공 마스터 탭 편명 클릭 → 꺽새 토글 (`eaf5b9d`)

기존: 꺽새 아이콘 버튼만 클릭 가능  
변경: 편명 셀 텍스트를 클릭해도 동일하게 꺽새 토글

```tsx
// Before
<td className="px-3 py-2 font-mono text-slate-700">{r.flight_num}</td>

// After
<td className="px-3 py-2">
  <button onClick={() => setExpandedId(prev => prev === r.id ? null : r.id)}
    className="font-mono text-slate-700 hover:text-brand transition">
    {r.flight_num}
  </button>
</td>
```

---

### 2. FlightsTab 좌석·항공료 필드 전면 통합

항차 마스터 > 항공 탭의 추가/편집 폼과 조회 패널에 좌석 분류·항공료 분류를 완전히 통합. 이로써 `FlightsEditor`(새행사등록) · `FlightsCard`(항차상세) · `FlightsTab`(항차마스터) 세 화면이 동일한 데이터 구조로 통일됨.

#### `FlightForm` 타입 확장

```ts
type FlightForm = {
  // 기존 필드 유지
  ...
  // 신규 추가
  seats_group:    string
  seats_indivi:   string
  seats_business: string
  fare_base:      string
  fare_fuel:      string
  fare_tax:       string
}
```

#### `EMPTY_FORM` 기본값 추가

```ts
seats_group: '0', seats_indivi: '0', seats_business: '0',
fare_base: '0', fare_fuel: '0', fare_tax: '0',
```

#### `initEditForm` — 기존 레코드에서 읽기

```ts
seats_group:    String(r.seats_group    ?? 0),
seats_indivi:   String(r.seats_indivi   ?? 0),
seats_business: String(r.seats_business ?? 0),
fare_base:      String(r.fare_base      ?? 0),
fare_fuel:      String(r.fare_fuel      ?? 0),
fare_tax:       String(r.fare_tax       ?? 0),
```

#### `FlightFormFields` — 좌석·항공료 수식 UI 추가

편명/날짜/시각 그리드 아래에 두 섹션 추가. `FlightsEditor`와 동일한 패턴.

```
편명 | 출발지 | 도착지 | PNR
출발일 | 출발시간 | 도착일 | 도착시간
항공요금 | 통화
──────────────────────────────────────── (border-t)
그룹(석) + 인디비(석) + 비즈니스(석) = 총 N석  ← 실시간 합산
──────────────────────────────────────── (border-t)
운임(원) + 유류할증료(원) + 발권피(원) = N원   ← 실시간 합산
```

실시간 합산은 `useState` 기반 `form` 값을 직접 계산:
```ts
const totalSeats = (Number(form.seats_group) || 0) + ...
const totalFare  = (Number(form.fare_base) || 0) + ...
```

#### `insertVoyageFlight` · `updateVoyageFlight` 호출부 확장

```ts
seats_group:    Number(form.seats_group)    || 0,
seats_indivi:   Number(form.seats_indivi)   || 0,
seats_business: Number(form.seats_business) || 0,
fare_base:      Number(form.fare_base)      || 0,
fare_fuel:      Number(form.fare_fuel)      || 0,
fare_tax:       Number(form.fare_tax)       || 0,
```

`addMut`(추가)과 `editMut`(편집) 양쪽에 모두 반영.

## 세 화면의 항공 데이터 구조 비교

| 화면 | 테이블 | 좌석/항공료 입력 | 구간(편명/날짜) |
|------|--------|-----------------|----------------|
| FlightsTab (항차 마스터) | `voyage_flights` | ✅ 폼 + SeatsPanel | 단일 (TIMESTAMPTZ 기반) |
| FlightsEditor (새행사 등록) | `flights` | ✅ 폼 | 다중 구간 (JSONB) |
| FlightsCard (항차 상세) | `flights` | ✅ 폼 | 다중 구간 (JSONB) |

> **차이점**: `voyage_flights`는 DST를 반영한 TIMESTAMPTZ 기반의 단일 구간 레코드. `flights`는 날짜/시각 문자열 + JSONB 다중 구간. 두 테이블은 독립적으로 운용됨.
