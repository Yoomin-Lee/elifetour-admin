### 1. 항차 검색 — 선택 모드 + 선택 삭제

#### 배경

"백업된 데이터를 다른 곳에 이관하고, 여기서는 삭제할 때 수월하도록" 항차 검색에 전체 선택·선택 삭제 기능을 요청받음. 항차 삭제는 admin 전용 RLS 정책이 걸려있어(`VoyageSearch.tsx`의 기존 단일 삭제와 동일 기준), 체크박스·삭제 버튼·확인 모달 전부 `isAdmin`일 때만 노출.

#### 1차 구현 → 선택 모드 토글로 재구성

처음엔 체크박스 컬럼을 admin이면 항상 보이게 만들었는데, 사용자가 명확한 스펙으로 재요청:
- 기본 상태엔 체크박스 컬럼을 완전히 렌더링하지 않음(숨김 처리 아님)
- 툴바에 '선택' 버튼 → 클릭 시 선택 모드 진입(체크박스 컬럼 등장, 버튼이 '취소'로 변경)
- '취소' 클릭 시 선택 모드 해제 + 선택 상태 전부 초기화
- 진입/해제 시 테이블에 `transition-[width]`를 줘서 폭(1160↔1192px)이 부드럽게 바뀌도록 함
- '삭제' 버튼은 선택 모드일 때만 노출, 0개 선택이면 비활성화

삭제는 `ConfirmDeleteModal`로 개수와 함께 명시적 확인을 받고, 여러 건을 `Promise.all(ids.map(deleteVoyage))`로 한 번에 처리.

#### 체크박스 UI 재작업

브라우저 기본 체크박스가 "사이트 이미지와 안 어울린다"는 피드백으로, 브랜드 컬러(`bg-brand`/`border-brand`) + lucide `Check` 아이콘 조합의 커스텀 `Checkbox` 컴포넌트(`src/components/ui/checkbox.tsx`)를 새로 만들어 교체. 이후 엑셀 내보내기의 시트 선택에도 재사용.

### 2. 엑셀 내보내기 기능 신설 (관리자 메뉴)

#### 기본 골격

사이드바 관리자 그룹에 '엑셀 내보내기'를 '직원 관리' 위에 추가(`/export`, admin 전용). 항차 마스터 + 연결된 항공(마스터)·항공좌석(보유현황)·기항지·취소료·히스토리·피드백·호텔·캐빈등급(보유현황)·결제스케줄 전체를 시트별로 나눠 하나의 xlsx로 내보내는 `exportAllVoyageData`를 `src/lib/excel.ts`에 작성. 각 시트에 사람이 읽을 수 있는 "행사명"을 넣어 이관 후에도 어떤 항차 데이터인지 알아볼 수 있게 함. 열 너비는 헤더·값 중 최대 폭(한글 2칸 계산) 기준으로 자동 계산.

사용자가 실제로 다운로드해보고 "ID·생성일·수정일은 필요 없다"는 피드백으로 세 컬럼 전부 제거.

#### 연도별 필터

"연도별로 뽑을 수 있게" 요청으로 연도 선택 드롭다운 추가. 처음엔 단일 선택(`YearSelect`)으로 시작했다가, 다른 화면들과 마찬가지로 다중 선택 요청이 들어와 `MultiSelectDropdown`으로 교체 — 여러 연도를 OR로 걸러 하나의 파일에 내보낼 수 있음(`exportAllVoyageData(years, sheetKeys)`가 `voyage_id` 기준으로 전 시트 공통 필터링).

이 과정에서 `YearSelect` 자체의 UX도 다듬음: 패널을 트리거 왼쪽 정렬로, 트리거 폭에 맞춰 최소폭 지정, '전체 연도'와 목록 사이 구분선 + 체크 아이콘, `max-h-[240px]` 스크롤, 뷰포트 하단이 부족하면 위로 열리는 flip 로직까지 추가했으나, 최종적으로 이 화면은 다중선택(`MultiSelectDropdown`, Radix Popover 기반이라 충돌 회피·위치 조정이 이미 내장됨)으로 넘어가면서 `YearSelect`는 다른 탭(결제·항차상세 등)에 그대로 남음.

#### 포함 시트도 선택 가능하게

"포함되는 시트도 선택 가능했으면" 요청에 따라 정적 목록이던 시트 안내를 `Checkbox` 기반 체크리스트로 전환. `excel.ts`에 `SHEET_DEFS`/`SheetKey`를 export하고 `exportAllVoyageData`가 `sheetKeys`를 받아 선택된 시트만 워크북에 추가하도록 확장. 전체 선택/해제 토글과, 0개 선택 시 내보내기 버튼 비활성화 + 안내 문구를 넣음.

### 3. 엑셀 내보내기 — 관리용 데이터 시트 스타일 전면 개선

#### 라이브러리 교체 (xlsx → exceljs)

"기본 스타일이라 가독성이 떨어진다"는 요청으로 헤더 강조색·Bold, 지브라 줄무늬, 얇은 테두리, 첫 행 고정, 자동 필터, 타입별 정렬·서식 등을 적용하려 했는데, 지금 쓰던 `xlsx`(SheetJS) 패키지는 **community edition이라 셀 스타일 작성이 유료 Pro 전용 기능**이라는 걸 확인 — 코드를 아무리 작성해도 저장 시 스타일 정보가 조용히 무시되는 구조였음. 스타일링을 실제로 지원하는 MIT 라이선스 `exceljs`를 새로 설치하고, `exportAllVoyageData`만 이 라이브러리로 재작성(항공편/기항지 엑셀 업로드 파싱, 입력양식 다운로드 등 스타일이 필요 없는 기존 기능은 그대로 `xlsx` 유지).

#### 스타일 내용

시트마다 각 컬럼에 `text`/`number`/`date`/`datetime` 타입을 태깅해 공통 헬퍼(`addStyledSheet`)에서 처리:
- 헤더: 브랜드 네이비(`#0F2849`) 배경 + 흰색 Bold, 가운데 정렬, 행높이 22
- 데이터 행: 타입별 정렬(텍스트 좌·숫자 우·날짜 가운데), 얇은 연회색(`#E2E8F0`) 테두리, 홀수/짝수 행을 옅은 배경(`#F8FAFC`)으로 구분, 행높이 18
- 숫자 `#,##0`, 날짜 `yyyy-mm-dd`, 일시 `yyyy-mm-dd hh:mm` 서식 — 날짜/일시 필드는 기존 문자열 값을 실제 JS `Date`로 파싱해 진짜 엑셀 날짜 타입이 되도록 함(표시 형식만 바뀌고 값이 가리키는 시점은 동일; 순수 날짜는 UTC 파싱으로 인한 하루 밀림을 막기 위해 로컬 연/월/일 컴포넌트로 직접 생성)
- 열 너비 자동계산 로직은 유지하되 Date 값은 포맷 길이 기준으로 추정
- 첫 행 고정(`views: [{state:'frozen', ySplit:1}]`) + 자동 필터(`autoFilter`) 추가

데이터 구조·컬럼 순서·값·필터링 로직은 전혀 바꾸지 않음. 브라우저 환경이라 Node 파일시스템 대신 `workbook.xlsx.writeBuffer()` → `Blob` → `<a download>` 클릭으로 다운로드 트리거하도록 변경. 실제 Supabase 로그인 브라우저 테스트는 이 환경에서 불가능해, 동일한 스타일링 코드 패턴을 목 데이터로 Node 스크립트에 옮겨 실행해보는 방식으로 API 호출이 전부 정상 동작하는지 별도 검증함.
