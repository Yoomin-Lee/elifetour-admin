## 변경 사항

### 1. 결제 탭 랜드·보험 카테고리 추가

**배경**  
기존 결제 탭은 크루즈·항공·호텔 3개 카테고리로 고정되어 있었음. 랜드사 비용과 여행자 보험료도 동일한 스케줄로 관리할 필요가 생겨 추가.

**변경 파일**

#### `src/types/database.ts`
```typescript
// Before
export type PaymentCategory = 'CRUISE' | 'FLIGHT' | 'HOTEL'

// After
export type PaymentCategory = 'CRUISE' | 'FLIGHT' | 'HOTEL' | 'LAND' | 'INSURANCE'
```

#### `src/components/voyages/tabs/PaymentTab.tsx`

**DB 스키마 변경** (SQL Editor 직접 실행)
```sql
ALTER TABLE payment_schedules
  DROP CONSTRAINT IF EXISTS payment_schedules_category_check;

ALTER TABLE payment_schedules
  ADD CONSTRAINT payment_schedules_category_check
  CHECK (category IN ('CRUISE', 'FLIGHT', 'HOTEL', 'LAND', 'INSURANCE'));
```

## 기술 포인트

### TypeScript Record 타입과 누락 키 검출
`Record<PaymentCategory, string>` 타입을 사용하면 새 카테고리 추가 시 해당 키가 없는 모든 Record 객체에서 컴파일 에러가 발생해 누락을 즉시 발견할 수 있다. CalendarTab의 `PAYMENT_STYLE`·`PAYMENT_CATEGORY_LABEL`도 동일 타입을 사용하고 있어 타입 체크만으로 수정 필요 파일을 빠짐없이 찾아낼 수 있었음.
