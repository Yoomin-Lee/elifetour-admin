## 변경 사항

### 1. 기항지 일정 날짜 컬럼 표시 수정 (`e2b8ac1`)

#### 문제
날짜 컬럼 너비가 미지정이어서 `27/09/10(목)` 중 연도(`27`)만 렌더링되는 현상.

#### 원인 분석
- 테이블에 `min-w-[480px]`만 설정되어 있고 날짜 `<TableHead>`에 너비 미지정
- `기항지` 컬럼이 나머지 공간을 모두 차지하면서 날짜 컬럼이 최소 너비로 압축됨
- `whitespace-nowrap`은 줄바꿈만 방지하고 컬럼 최소 너비를 보장하지 않음

#### 수정

```tsx
// Before
<Table className="min-w-[480px]">
  <TableHead className="whitespace-nowrap">날짜</TableHead>

// After
<Table className="min-w-[560px]">
  <TableHead className="w-[108px] whitespace-nowrap">날짜</TableHead>
  <TableCell className="whitespace-nowrap font-medium text-sm">{formatDate(d.date)}</TableCell>
```

- `w-[108px]` 고정: `27/09/10(목)` 10자를 여유 있게 표시
- `min-w` 480→560px: 날짜 컬럼 확보 후 전체 최소 너비 조정
- `text-sm` 명시: 기항지·구분 등 다른 컬럼과 폰트 크기 통일

### 2. 항공 조회 모드 구간 꺽새 토글 추가 (`FlightsCard.tsx`)

#### 배경
크루즈 캐빈 등급 클릭 시 꺽새가 자동으로 열려 세부 정보가 표시되는 UX와 동일하게, 항공 조회 모드에서도 편명·날짜·시각 구간 정보를 꺽새로 접고 펼칠 수 있어야 함.

기존 조회 모드는 구간 정보가 항상 펼쳐져 있어 항공편이 많을 때 화면이 길어지는 문제가 있었음.

#### 구현

**`expandedSet` 상태 추가**

```ts
const [expandedSet, setExpandedSet] = useState<Set<string>>(new Set())

function toggleExpanded(id: string) {
  setExpandedSet(prev => {
    const next = new Set(prev)
    if (next.has(id)) next.delete(id)
    else next.add(id)
    return next
  })
}
```

Set을 사용해 여러 항공편 카드가 독립적으로 열고 닫힐 수 있도록 구현.

**조회 모드 구간 섹션 변경**

```tsx
// Before: 항상 펼쳐진 구간 목록
{segs.length > 0 && (
  <div className="border-t ...">
    {segs.map(...)}
  </div>
)}

// After: 꺽새 토글
{segs.length > 0 && (
  <div className="border-t ...">
    <button onClick={() => toggleExpanded(f.id)} ...>
      {expandedSet.has(f.id) ? <ChevronDown /> : <ChevronRight />}
      편명 · 날짜 · 시각
      <span>{segs.length}구간</span>   ← 뱃지
    </button>

    {expandedSet.has(f.id) && (
      <div className="mt-2 space-y-1">
        {segs.map(...)}
      </div>
    )}
  </div>
)}
```

- 기본값: 접힘 (모든 카드 닫힘)
- 버튼 클릭 시 해당 항공편만 펼침/접음
- 구간 수 뱃지로 내용 유무를 접힌 상태에서도 확인 가능
- 편집 모드의 꺽새 버튼(`FlightDraftRow`)과 동일한 UI 패턴 유지

## 기술 포인트

### Set 기반 다중 토글 상태
단일 `boolean` 상태는 하나의 카드만 열 수 있음. `Set<string>`으로 확장하면 여러 카드가 독립적으로 열고 닫힐 수 있음. `id`를 키로 사용해 배열 인덱스 변경(삭제/재정렬) 시에도 안전함.

### 테이블 컬럼 너비 고정 규칙
`whitespace-nowrap`은 줄바꿈을 방지하지만 컬럼 최소 너비를 보장하지 않음. 날짜처럼 길이가 고정된 데이터는 `w-[Npx]`로 명시적으로 고정해야 함.
