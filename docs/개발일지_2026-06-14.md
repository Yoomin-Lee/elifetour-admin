### 항공 비행시간 자동 계산 유틸 구현 (date-fns-tz + DST)

**배경**
서머타임(DST)이 적용되는 구간(미서부, 유럽 등)에서 현지 시계 기준 비행시간 계산 오차 문제를 해결하기 위해 UTC 기반 계산 로직을 구현함.

**신규 파일**

| 파일 | 설명 |
|------|------|
| `src/lib/utils/flightCalc.ts` | 공항 IATA → IANA 타임존 맵, DST 반영 비행시간 계산 유틸 |
| `src/lib/queries/voyageFlights.ts` | Supabase CRUD (voyage_flights 테이블) |
| `src/hooks/useFlightCalc.ts` | React 실시간 비행시간 계산 훅 |

**핵심 로직**
- `fromZonedTime(localDatetimeStr, ianaTimezone)` — 현지 시각을 UTC로 변환
- `differenceInMinutes(arrUtc, depUtc)` — UTC 기준 비행시간(분) 계산
- 지원 공항 30개: ICN, SIN, DXB, LAX, SEA, FCO, VCE, BCN, DOH, IST, HKG, PVG, NRT 등

**의존성 추가**
```json
"date-fns": "^4.4.0",
"date-fns-tz": "^3.2.0"
```

## 트러블슈팅

| 문제 | 원인 | 해결 |
|------|------|------|
| 한글 깨짐 | PowerShell `Get-Content` CP949 인코딩 | `[System.IO.File]::ReadAllText(path, UTF8)` 사용 |
| `Invoke-WebRequest` 실패 | NonInteractive 모드 미지원 | `Invoke-RestMethod`로 교체 |
| INSERT 0 rows (silently) | `Invoke-RestMethod`의 한글 HTTP Body가 UTF-8로 전송되지 않아 WHERE 조건 불일치 | `System.Net.HttpWebRequest`로 교체, `ContentType = "application/json; charset=utf-8"` 명시 |
| UNION ALL INSERT 0 rows | 첫 SELECT 행에 명시적 타입 캐스트 누락 → PostgreSQL이 text로 추론 | `'2025-02-13'::date`, `'11:55'::time` 등 첫 행 캐스트 추가 |
| `function max(uuid)` 오류 | UUID 타입에 MAX() 없음 | `ORDER BY created_at DESC LIMIT 1` CTE 방식으로 우회 |
| itinerary_days 중복 행 | 동일 SQL 파일을 2회 실행 (1차 silent success, 2차 RETURNING 추가 재실행) | `TRUNCATE TABLE itinerary_days` 후 1회만 재실행 |
