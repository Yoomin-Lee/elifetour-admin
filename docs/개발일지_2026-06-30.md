### 7. 피드백 크로스 캐시 동기화 — 마스터 탭 ↔ 항차 상세 양방향 연동

#### 배경

피드백 마스터 탭(`FeedbackMasterTab`)과 항차 상세 피드백 카드(`FeedbackCard`)는 각각 별도의 React Query 캐시 키를 사용:
- 마스터 탭: `['all-feedback']`
- 항차 상세: `['feedback', voyageId]`

마스터 탭에서 수정·삭제해도 항차 상세 피드백 카드에 즉시 반영되지 않는 문제.

#### 수정

**`FeedbackCard.tsx`** — 이미 완료:

```ts
const invalidateAll = () => {
  qc.invalidateQueries({ queryKey: ['feedback', voyageId] })
  qc.invalidateQueries({ queryKey: ['all-feedback'] })
}
```

- `addMutation`, `updateMutation`, `deleteMutation` 모두 `invalidateAll()` 호출

**`FeedbackMasterTab.tsx`**:

```ts
const invalidateBoth = (voyageId: string) => {
  qc.invalidateQueries({ queryKey: ['all-feedback'] })
  qc.invalidateQueries({ queryKey: ['feedback', voyageId] })
}

// updateMut — onSuccess에서 editingVoyageId로 양쪽 invalidate
const updateMut = useMutation({
  onSuccess: () => {
    setEditingId(null)
    if (editingVoyageId) invalidateBoth(editingVoyageId)
    else qc.invalidateQueries({ queryKey: ['all-feedback'] })
  },
})

// deleteMut — voyageId를 variables에 포함하여 양쪽 invalidate
const deleteMut = useMutation({
  mutationFn: ({ id }: { id: string; voyageId: string }) => deleteFeedbackLog(id),
  onSuccess: (_, variables) => invalidateBoth(variables.voyageId),
})
```

- `startEdit(r)`: `setEditingVoyageId(r.voyage_id)` 추가
- `cancelEdit()`: `setEditingVoyageId(null)` 추가
- `handleDelete(r)`: `deleteMut.mutate({ id: r.id, voyageId: r.voyage_id })` 로 변경

#### 결과

마스터 탭에서 피드백 수정·삭제 → 항차 상세 피드백 카드에도 즉시 반영.

##### 8-1. 잔여율 시각화 — MiniProgressBar

```ts
function MiniProgressBar({ total, remaining, className = '' }) {
  if (total === 0) return null
  const pct = Math.round((remaining / total) * 100)
  // 색상: ≥50% 초록 / 20~49% 노랑 / <20% 빨강
  return (
    <div className={`h-1 w-full rounded-full bg-slate-200 overflow-hidden ${className}`}>
      <div className={`h-full rounded-full ${barColor(pct)}`} style={{ width: `${pct}%` }} />
    </div>
  )
}
```

- 요약 테이블 `잔여캐빈` 컬럼: 숫자 아래 `MiniProgressBar` 추가
- InventoryPanel 크루즈 선실 테이블 `잔여` 셀: 등급별로 동일하게 적용
- `barColor`: `pct >= 50` → `bg-emerald-400` / `pct >= 20` → `bg-amber-400` / 나머지 → `bg-red-400`

##### 9-2. 저장 로직 — saveMut

```ts
const saveMut = useMutation({
  mutationFn: async () => {
    // 1. 캐빈 등급: saveCabinGrades (신규/수정/삭제 일괄 처리)
    await saveCabinGrades(voyageId, draftGrades.map(g => ({
      ...(g._isNew ? {} : { id: g.id }), // _isNew면 id 제외 → INSERT
      grade, total, reserved, price_per_person, ccf, nccf, tax, tip, currency, agent, sort_order
    })), delGradeIds.filter(id => !id.startsWith('__new__')))

    // 2. 항공: updateVoyageFlight (좌석·운임만, 경로·시각은 read-only)
    await Promise.all([
      ...draftFlights.filter(f => !delFlightIds.includes(f.id))
        .map(f => updateVoyageFlight(f.id, { seats_group, seats_indivi, seats_business, fare_base, fare_fuel, fare_tax })),
      ...delFlightIds.map(id => deleteVoyageFlight(id)),
    ])

    // 3. 호텔: addHotel / updateHotel / deleteHotel
    await Promise.all([
      ...delHotelIds.filter(id => !id.startsWith('__new__')).map(id => deleteHotel(id)),
      ...draftHotels.filter(h => h._isNew).map(h => addHotel(voyageId, { hotel_name, stay_date, room_rate, currency, sort_order })),
      ...draftHotels.filter(h => !h._isNew).map(h => updateHotel(h.id, { hotel_name, stay_date, room_rate, currency })),
    ])
  },
  onSuccess: () => { invalidateAll(); setEditMode(false); toast.success('저장됐습니다') },
})
```

- `saveCabinGrades`는 내부적으로 `updateVoyage(cabin_total, cabin_remaining)`도 호출하므로 항차 합계 자동 갱신
