## 작업 요약

### 항차 마스터 '보유 현황' 탭 신설

#### 배경

크루즈·항공·호텔 데이터가 각각 별도 탭에 분산되어 있어, 행사별 전체 보유 현황을 한눈에 파악하기 어려운 문제 해결.

---

#### 구현 내용

**신규 파일**
- `src/components/voyages/tabs/InventoryTab.tsx`

**수정 파일**
- `src/pages/VoyageMaster.tsx` — 탭 목록·라우팅에 '보유현황' 추가 (항차 상세 ↔ 크루즈 사이)

---

#### 기능 상세

**메인 테이블**

| 컬럼 | 내용 |
|------|------|
| 행사명 | 클릭 시 항차 상세로 이동 (ExternalLink 아이콘) |
| 출발일 | YYYY-MM-DD |
| 크루즈 | ship_name 우선, 없으면 cruise_line |
| 항공 | airline / airline_return 조합 |
| 호텔 | 첫 번째 호텔명 (복수 시 "외 N곳") |
| 보유캐빈 | cabin_grades.total 합계 |
| 잔여캐빈 | cabin_grades.(total-reserved) 합계, 0이면 빨간색 |
| 보유좌석 | voyage_flights.(seats_group+seats_indivi+seats_business) 합계 |

행사 정렬: 출발일 최신순 (fetchVoyages 기본 정렬 유지)

**필터**
- 연도별 YearSelect 드롭다운
- 상태별 FieldSelect (미오픈/판매중/마감/출발완료/취소/전체)
- 통합 검색: 행사명·선박명·선사·항공사·호텔명

**꺾새 확장 서브 패널 (InventoryPanel)**

3개 섹션이 세로로 구분선(divide-y)으로 분리됨.

1. **크루즈 선실** (Ship 아이콘, 파란색)
   - 등급 | 보유 | 예약 | 잔여 | 에이전트 | CCF | NCCF | TAX | TIP | 캐빈가
   - 잔여 0이면 빨간색 강조
   - 2개 이상 등급이면 합계 행 자동 표시

2. **항공 좌석** (Plane 아이콘, 하늘색)
   - 편명 | 구간(출발→도착, 현지 날짜+시각) | 그룹 | 인디비 | 비즈니스 | 총좌석 | 운임 | 유류할증 | 발권피 | 항공료
   - 현지 시각 변환: `getAirportTimezone` + `date-fns-tz/toZonedTime`
   - 2편 이상이면 합계 행 자동 표시

3. **호텔 객실** (Building2 아이콘, 황색)
   - 호텔명 | 투숙일 | 요금
   - 등록 없으면 "등록된 호텔이 없습니다" 안내

---

#### 데이터 쿼리 전략

기존 쿼리 함수 및 쿼리 키 재활용 (별도 네트워크 요청 없이 캐시 공유):

| 데이터 | queryKey | 함수 |
|--------|----------|------|
| 행사 목록 | `['voyages']` | `fetchVoyages` |
| 캐빈 등급 | `['all-cabin-grades']` | `fetchAllCabinGrades` |
| 항공편 | `['all-voyage-flights']` | `fetchAllVoyageFlights` |
| 호텔 | `['all-hotels']` | `fetchAllHotels` |

각 배열을 `voyage_id` 기준으로 `useMemo`로 매핑(gradeMap, flightMap, hotelMap)하여 O(1) 조회.

---

#### 취소 행사 처리

- 취소 상태 행사는 `opacity-50` 적용
- 행사명 `line-through` 표시
- 항차 상세 링크 버튼 비활성화 (클릭 불가)
