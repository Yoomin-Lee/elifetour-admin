### 1. 핵심 구조 수정 — QueryClient 공유

**배경**
`VoyageSearch`(항차검색 탭)가 자체 `QueryClient`를 생성하고 있어서, 다른 탭(CruiseTab 등)에서 데이터를 수정해도 OverviewCard나 ProductTab에 즉시 반영되지 않는 문제가 있었음.

**원인**
```
VoyageMaster (QC: qc1)
  └─ CruiseTab            → qc1 캐시 사용 (invalidate 반영됨)
  └─ SearchTab → VoyageSearch (QC: qc2 ← 독립 생성!)
       └─ OverviewCard     → qc2 캐시 사용 (qc1 invalidate 무시됨)
```

**수정**: `VoyageSearch.tsx`에서 `QueryClientProvider` 제거

```tsx
// 수정 전
const queryClient = new QueryClient({ ... })
export default function VoyageSearch() {
  return (
    <QueryClientProvider client={queryClient}>
      <VoyageSearchInner />
    </QueryClientProvider>
  )
}

// 수정 후
export default function VoyageSearch() {
  return <VoyageSearchInner />
}
```

이제 모든 탭이 `VoyageMaster`의 단일 QC를 공유함. CruiseTab에서 캐빈 수정 → `['voyages']` 무효화 → ProductTab·OverviewCard·VoyageCombobox 즉시 반영.

### 3. FlightsTab — 행별 편집/삭제 + 신규 추가

**파일**: `src/components/voyages/tabs/FlightsTab.tsx`

`voyage_flights` 테이블 대상.

**기능**:
- 각 행 ✏️ → 행 아래 확장 편집 폼 (현지 날짜+시각 입력)
- 각 행 🗑️ → `deleteVoyageFlight(id)` 즉시 삭제
- 헤더 "추가" 버튼 → 상단에 신규 항공편 폼 (행사 선택 드롭다운 + 전체 필드)

**핵심**: 편집 폼에 현지 시각 역산 표시

```ts
// UTC → 현지 시각 변환 (편집 폼 초기값)
function initEditForm(r: VoyageFlight): FlightForm {
  const dep = localDt(r.dep_datetime, r.dep_airport)  // toZonedTime 활용
  const arr = localDt(r.arr_datetime, r.arr_airport)
  return { departureDate: dep.form.date, departureTime: dep.form.time, ... }
}
```

저장 시: `updateVoyageFlight(id, input)` → 내부적으로 `calcFlightDuration()` 재계산 → UTC TIMESTAMPTZ 업데이트
