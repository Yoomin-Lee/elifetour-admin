## 2. tsconfig baseUrl deprecated 경고 제거

### 배경
TypeScript 5.0+에서 `paths`만 단독으로 사용할 경우 `baseUrl`이 불필요하며 TS5101 deprecated 경고 발생.

### 수정

```json
// tsconfig.json — 삭제된 줄
"baseUrl": "."
```

`paths`만 존재하는 경우 `baseUrl` 없이도 `@/*` alias 정상 동작.
