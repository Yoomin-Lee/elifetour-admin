## 변경 사항

### 1. 기항지 루트 관리 드래그 앤 드롭 (`ItineraryPresetManager.tsx`)

**`@dnd-kit` 기반 완전 재작성**

기존 파일에는 `GripVertical` 아이콘만 있고 실제 드래그 동작이 없었음. `@dnd-kit/core`, `@dnd-kit/sortable`, `@dnd-kit/utilities` 설치 후 전면 재작성.

**구조**

```
ItineraryPresetManager (외부 DndContext — 루트 순서)
└─ SortablePresetItem (루트 카드 — useSortable)
   └─ DndContext (내부 — 기항지 순서)
      └─ SortablePortRow (기항지 행 — useSortable)
```

**루트 목록 순서 변경**
- `sorted` state로 낙관적 UI 업데이트 (드래그 즉시 시각 반영)
- `handlePresetDragEnd`: `arrayMove` → `sorted` 갱신 → `sort_order` 변경된 항목만 `updateItineraryPreset` 호출
- DB 반영은 드롭 시 자동 (저장 버튼 불필요)

**루트 내 기항지 순서 변경**
- 각 `SortablePresetItem` 내부에 별도 `DndContext` 구성 (중첩 DnD)
- `PortWithKey` 타입: `PresetPort & { _key: string }` — 안정적 키 관리용
- `handlePortDragEnd`: `arrayMove` + `setDirty(true)`
- 기항지 순서 변경은 기존 "저장" 버튼 클릭 시 DB 반영 (루트 레이블/박수 변경과 동일 흐름)

**UX**
- 드래그 중 `opacity: 0.45` 피드백
- `PointerSensor` + `KeyboardSensor` (접근성)
- 루트 헤더: 그립 핸들 | 펼치기/접기 | 루트명 인라인 편집 | 박수 | 저장 | 삭제

### 2. 취소료 구간 드래그 앤 드롭 (`CancellationEditor.tsx`)

**`SortablePolicyRow` 래퍼 컴포넌트 추가**

```tsx
function SortablePolicyRow({ id, children }) {
  const { attributes, listeners, setNodeRef, transform, transition, isDragging } = useSortable({ id })
  return (
    <div ref={setNodeRef} style={{ transform, transition, opacity: isDragging ? 0.45 : 1 }}
         className="flex gap-2 items-start rounded-lg border border-slate-100 p-2">
      <div {...attributes} {...listeners} className="mt-2 cursor-grab ...">
        <GripVertical />
      </div>
      {children}
    </div>
  )
}
```

- `useFieldArray`에서 `move` 추출 (기존에 `append, remove, replace`만 사용 중)
- `handlePolicyDragEnd`: `fields.findIndex` → `move(oldIdx, newIdx)` 호출
- `DndContext` + `SortableContext`로 fields 목록 감쌈
- 순서 변경은 폼 내부에서 즉시 반영, 행사 최종 저장 시 DB 반영

### 3. 기항지 일정 날짜 표시 최적화 (`ItineraryEditor.tsx`, `date-picker.tsx`)

**문제**  
기항지 행의 날짜 DatePicker가 기본 포맷(`"2026년 6월 24일 (화)"`, 약 15자)을 사용하고 있어, 5열 그리드의 좁은 첫 번째 컬럼에서 줄바꿈 발생.

**해결 1 — `ItineraryEditor.tsx`**  
```tsx
// 변경 전
<DatePicker value={field.value ?? ''} onChange={field.onChange} placeholder="날짜 선택" />

// 변경 후
<DatePicker value={field.value ?? ''} onChange={field.onChange} placeholder="날짜" size="sm" />
```
- `size="sm"` → `"yy/MM/dd"` 포맷 (`"26/06/24"`, 8자), `min-h-[28px]` 높이로 다른 `h-7` 입력 필드와 통일

**해결 2 — `date-picker.tsx`**  
```tsx
// 변경 전
<span className={value ? 'font-medium text-slate-800 tabular-nums' : 'text-slate-400'}>

// 변경 후
<span className={`min-w-0 truncate ${value ? '...' : '...'}`}>
```
- `min-w-0 truncate` 전역 추가 — 어느 DatePicker든 좁은 컬럼에서 줄바꿈 대신 말줄임(`…`) 처리

## 기술 메모

- **중첩 DnD**: `@dnd-kit`는 중첩 `DndContext`를 지원함. 바깥 Context는 루트 순서, 안쪽 Context는 기항지 순서를 각각 담당. `event.stopPropagation`이 필요 없음 — 드래그 이벤트가 상위 Context로 버블링되지 않음.
- **`useFieldArray.move`**: React Hook Form의 `useFieldArray`가 내장 제공. `arrayMove` + `setValue` 조합 없이 한 번에 순서 변경 가능.
- **낙관적 순서 업데이트**: 루트 목록은 `presets` query 외에 `sorted` 로컬 state를 별도 유지. `useEffect`로 query 데이터 변경 시 sync. 드래그는 `sorted`만 갱신해 즉각 반응, DB 요청은 백그라운드 전송.
- `tsc --noEmit` → 오류 없음
- 배포: GitHub Actions 자동 (main push)
