## 1. 취소료 기준일 DatePicker UI 통일

### 배경
취소료 편집(`CancellationEditor`)의 "기준일 직접 지정" 입력 필드가 브라우저 기본 `<input type="date">`를 사용하고 있어, 다른 날짜 입력과 UI가 일치하지 않음.

### 수정
`<Input type="date" {...register(...)}>` → 커스텀 `<DatePicker>` 컴포넌트로 교체.

```tsx
<DatePicker
  value={watchedPolicies?.[i]?.reference_date ?? ''}
  onChange={v => setValue(`policies.${i}.reference_date`, v)}
  placeholder="기준일 선택"
/>
```

## 2. 통화 드롭다운 5종 통일 + 기호 앞 형식

### 배경
앱 전반에 걸쳐 통화 목록이 파일마다 달랐음 (GBP, AUD 포함 등). 기호 표시 형식도 혼재.

### 통화 목록 통일
`['KRW', 'USD', 'EUR', 'SGD', 'JPY']` 5종으로 고정. GBP·AUD 제거.

### 기호 앞 형식 통일
| 통화 | 기호 | 예시 |
|------|------|------|
| KRW  | ₩    | ₩1,200,000 |
| USD  | $    | $1,200 |
| EUR  | €    | €1,100 |
| SGD  | S$   | S$1,600 |
| JPY  | ¥    | ¥130,000 |

```ts
const sym: Record<string, string> = { KRW: '₩', USD: '$', EUR: '€', SGD: 'S$', JPY: '¥' }
const prefix = sym[currency] ?? (currency + ' ')
return prefix + price.toLocaleString(currency === 'KRW' ? 'ko-KR' : 'en-US')
```

## 3. 크루즈 탭 캐빈가 CCF/NCCF/TAX/TIP 계산식

### 배경
크루즈 캐빈가는 CCF(크루즈 운임) + NCCF(항만세) + TAX(세금) + TIP(봉사료) 4개 항목의 합산으로 구성됨. 기존에는 총액만 저장·표시하여 구성 내역 파악이 불가.

### DB 마이그레이션

```sql
-- supabase/migrations/20260623000000_cabin_grade_price_breakdown.sql
ALTER TABLE cabin_grades
  ADD COLUMN IF NOT EXISTS ccf  numeric,
  ADD COLUMN IF NOT EXISTS nccf numeric,
  ADD COLUMN IF NOT EXISTS tax  numeric,
  ADD COLUMN IF NOT EXISTS tip  numeric;
```

### calcTotal 로직

```ts
function calcTotal(g): number | null {
  const sum = (g.ccf ?? 0) + (g.nccf ?? 0) + (g.tax ?? 0) + (g.tip ?? 0)
  if (sum > 0) return sum
  return g.price_per_person  // 하위 호환 폴백
}
```

### UI — GradesPanel 2행 레이아웃

**조회 모드**
- 1행: 등급 · 보유 · 예약 · 잔여
- 2행: `CCF $X + NCCF $X + TAX $X + TIP $X = $캐빈가`

**편집 모드**
- 1행: 등급 선택, 보유/예약 수량 입력
- 2행: CCF/NCCF/TAX/TIP 숫자 입력 → 실시간 합산 표시, 통화 선택

편집 시작 시 `price_per_person: null` 로 초기화하여, 4개 항목을 모두 지우면 합계가 `—`로 표시되도록 보장.

## 6. 크루즈 탭 캐빈 다중 등급 지원

### 배경
하나의 항차에 여러 캐빈 등급(4D, 2D, BA2 등)을 보유하는 경우가 있음. 기존 GradesPanel은 단일 등급만 편집 가능.

### GradesPanel 다중 등급 편집

단일 `draft: DraftGrade | null` → `drafts: DraftGrade[]` 배열로 변경.

| 버튼 | 동작 |
|------|------|
| `+ 등급 추가` | 빈 등급 카드를 배열에 추가 |
| 휴지통 | 해당 등급 삭제 (기존 DB 등급은 soft-delete → `deletedIds` 전달) |
| 저장 | 전체 배열을 `saveCabinGrades`에 한 번에 전달 |

**조회 모드** 버튼 배치: `+ 등급 추가` (바로 편집 진입) + `편집`.

```ts
function startEditWithNew() {
  setDrafts([...gradesToDrafts(), makeDraft()])
  setIsEditing(true)
}
```

### ▶ 패널 항상 표시

기존 `{isExpanded && !isEdit && <GradesPanel />}` → `{isExpanded && <GradesPanel />}`.  
인라인 편집(연필) 중에도 등급 현황 패널이 닫히지 않아 `+ 등급 추가` 버튼에 항상 접근 가능.

### 인라인 편집 2행 분리

- **1행**: 선사 · 크루즈 선박명 · 에이전트 · 보유캐빈 · 잔여캐빈
- **2행** (border-t 구분선): 캐빈등급 · CCF · NCCF · TAX · TIP · 통화

### 다중 등급 서브 행 자동 표시

2개 이상 등급 보유 시 메인 행 바로 아래에 2번째 이후 등급을 서브 행으로 표시.  
▶ 클릭 없이 각 등급명 + 보유/예약/잔여 + 캐빈가를 즉시 확인 가능.  
서브 행도 클릭 시 ▶ 패널 토글.

```
[25/11 동부지중해]  ROYAL  Anthem  4D   10   6   4   $1,200
                                   └ 2D   5   2   3   $1,500
```

### 메인 열 합산

보유·예약·잔여는 전체 등급 합산값 표시.  
캐빈등급 컬럼은 첫 번째 등급명만 표시 ('외 N' 제거 — 서브 행으로 대체).

### 캐빈등급 셀 클릭 → 패널 토글

```tsx
<td onClick={() => toggleExpand(v.id)} className="cursor-pointer hover:text-brand ...">
  {gradeLabel}
</td>
```
