**해결 (`pending ref` 패턴)**  
```typescript

const mmPending = useRef(value?.split(':')[1] ?? '')

// keyDown에서 setHh와 동시에 ref도 즉시 갱신
hhPending.current = val
setHh(val)

// blur에서 stale closure 대신 ref 사용
function handleHhBlur() {
  const curHh = hhPending.current  // 항상 최신값
  ...
}
```

**결과**: "11" 입력 → "11:00" 정상 처리. 앱 전체 TimePicker에 동일하게 적용.

```typescript
function focusNextInput(el: HTMLElement) {
  const all = Array.from(document.querySelectorAll<HTMLElement>(
    'input:not([disabled]):not([type="hidden"]), select:not([disabled]), textarea:not([disabled])'
  ))
  const idx = all.indexOf(el)
  if (idx !== -1 && idx + 1 < all.length) all[idx + 1].focus()
}

function selectDay(day: Date) {
  onChange(format(day, 'yyyy-MM-dd'))
  setOpen(false)
  if (inputRef.current) focusNextInput(inputRef.current)  // 추가
}
```

- 캘린더 클릭 선택 + YYMMDD 6자리 빠른 입력 완료 모두 동일 동작

## 기술 포인트

### React 배칭과 stale closure 우회
React 18의 자동 배칭으로 인해 `setState` 호출 직후 같은 이벤트 루프에서 발생하는 `blur`는 이전 state를 읽음. `useRef`로 parallel tracking하면 동기적으로 최신값 접근 가능.

### UI-level 카테고리 마이그레이션
DB 스키마 변경 없이 레거시 카테고리를 새 카테고리로 점진 이동:
1. 표시: 두 카테고리를 동일 그룹으로 필터
2. 저장: `onSave` 시 레거시값을 신규값으로 coerce
3. 데이터는 사용자가 섹션을 다시 저장할 때마다 자동 마이그레이션

### `focusNextInput` 유틸 패턴
DOM에서 모든 focusable input 목록을 수집해 현재 element 다음으로 이동. 캘린더 버튼은 `<button>` 태그라 목록에 포함되지 않아 올바른 다음 input으로 바로 이동.
