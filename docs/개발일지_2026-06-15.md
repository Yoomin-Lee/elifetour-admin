### Phase 3 — 항차검색 탭 전체 편집 기능 구현

**배경**
항차검색(VoyageSearch) 탭의 카드들이 전부 읽기 전용이었음. 등록된 항차의 기본 정보, 항공, 기항지, 취소료를 수정·추가·삭제할 수 없어 별도 VoyageNew 페이지로 돌아가야 했음. 편집 기능을 카드 인라인으로 구현하여 조회-편집 흐름을 단일 화면에서 처리할 수 있게 됨.

---

### 1. Backend — voyages.ts CRUD 함수 추가

`src/lib/queries/voyages.ts`에 다음 함수를 추가했다:

| 함수 | 설명 |
|------|------|
| `updateVoyage(id, patch)` | 항차 기본 정보 업데이트 |
| `saveFlight(voyageId, data, id?)` | 항공편 insert/update (id 있으면 update) |
| `deleteFlightRow(id)` | 항공편 삭제 |
| `saveItineraryDay(voyageId, data, id?)` | 기항지 일정 insert/update |
| `deleteItineraryDay(id)` | 기항지 일정 삭제 |
| `saveCancellationPolicy(voyageId, data, id?)` | 취소료 정책 insert/update |
| `deleteCancellationPolicy(id)` | 취소료 정책 삭제 |

`saveFlight`, `saveItineraryDay`, `saveCancellationPolicy`는 `id` 인자로 upsert 패턴을 구현함:
- `id` 없음 → `INSERT`
- `id` 있음 → `UPDATE WHERE id = ?`

### 2. OverviewCard — 인라인 편집 모드

**파일**: `src/components/voyages/OverviewCard.tsx`

카드 헤더에 ✏️ 버튼 추가. 클릭 시 편집 모드로 전환:
- 모든 행이 `<Input>` / `<Select>` 로 변환
- ✓ 저장 / ✗ 취소 버튼 표시
- `updateVoyage` mutation으로 저장, 성공 시 `['voyages']` 쿼리 무효화 → 콤보박스 자동 갱신

**편집 가능 필드**: 지역/상품명, 상태, 출발일, 귀국일, 항공사, 선사, 크루즈, 보유 캐빈, 잔여 캐빈, 고객 수, 인솔자, 호텔

**UX 패턴**:
```
편집 버튼 클릭 → 로컬 form state 초기화 (현재 voyage 값)
→ 편집 모드 진입 → 필드 수정
→ 저장 클릭 → useMutation → onSuccess: invalidate voyages + exit edit
```

### 3. FlightsCard / ItineraryCard / CancellationCard — 행 CRUD

**파일**:
- `src/components/voyages/FlightsCard.tsx`
- `src/components/voyages/ItineraryCard.tsx`
- `src/components/voyages/CancellationCard.tsx`

세 카드 모두 동일한 **Draft State 패턴**으로 구현:

```ts
type DraftRow = {
  _key: string     // React key (db id 또는 "new-{timestamp}")
  _isNew: boolean  // 신규 행 여부
  _deleted: boolean // 삭제 예약 여부
  id: string       // DB 실제 id
  ...fields
}
```

**편집 모드 진입 시**: 현재 props 데이터를 draft state로 복사  
**행 추가**: `_isNew: true` 빈 행 append  
**행 삭제**: `_isNew`면 배열에서 제거, 기존 행이면 `_deleted: true` 마킹  
**저장**: draft를 순회하여:
- `_deleted && !_isNew` → delete
- `_isNew && !_deleted` → insert  
- `!_isNew && !_deleted` → update

**VoyageSearch.tsx 변경**: 세 카드에 `voyageId` prop 추가 전달

```tsx
// 변경 전
<FlightsCard flights={...} />
// 변경 후
<FlightsCard flights={...} voyageId={voyageId} />
```
