### 2. 항차 개요·등록 폼 상품가(KRW) 필드 추가

#### 배경

항목별 상품가를 개요에서 바로 확인·수정하고, 새 행사 등록 시에도 입력 가능하도록 요청.

#### DB 변경

**마이그레이션 (`20260629000002_voyage_product_price.sql`)**

```sql
ALTER TABLE voyages ADD COLUMN IF NOT EXISTS product_price BIGINT;
```

> 수동 실행 완료 (Supabase 대시보드 SQL Editor).

#### 수정 파일

| 파일 | 변경 내용 |
|------|-----------|
| `src/types/database.ts` | `Voyage` 인터페이스에 `product_price: number \| null` 추가 |
| `src/lib/queries/voyages.ts` | `fetchVoyages` select 목록에 `product_price` 추가 |
| `src/lib/schemas/voyage.ts` | `voyageFormSchema`에 `product_price` 필드 추가 |
| `src/components/voyages/OverviewCard.tsx` | 뷰: 호텔 아래 `N원` 표시 / 편집: 숫자 입력 + 원 레이블 |
| `src/components/voyages/BasicInfoSection.tsx` | 기본정보 섹션에 상품가(원) 필드 추가 |

#### UX 개선

- 입력 시 천 단위 콤마 자동 적용 (`toLocaleString()`)
- 편집 모드 진입 시 기존 값도 콤마 포맷으로 초기 표시
- 저장 시 콤마 제거 후 정수 저장

### 4. 항차 검색(ProductTab) 상품가 컬럼 추가

#### 배경

항차 검색 전체 그리드에서 상태↔고객 사이에 상품가 표시 요청.

#### 수정 (`src/components/voyages/tabs/ProductTab.tsx`)

- 상태↔고객 사이 상품가 컬럼 추가 (가운데 정렬)
