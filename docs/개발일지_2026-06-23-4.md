## 변경 사항

### 1. 기항지 필드 확장: 구분 / 통화 / 비용(인당) / 비고

**영향 파일**
- `src/lib/schemas/voyage.ts`
- `src/components/voyages/ItineraryEditor.tsx`
- `src/components/voyages/ItineraryCard.tsx`

**스키마 변경** (`voyage.ts`)
- `itinerarySchema`에 `cost: z.coerce.number().nullable().optional()` 추가
- `itinerarySchema`에 `cost_currency: z.string().optional()` 추가
- 이미 추가된 `category` 필드와 함께 기항지 행당 4개 확장 필드 완성

**새 행사 추가 폼** (`ItineraryEditor.tsx`)
- `CURRENCY_OPTIONS` 상수 추가 (KRW / USD / EUR / SGD / JPY)
- `EMPTY_DAY`에 `cost: null, cost_currency: 'USD'` 추가
- 프리셋 불러오기 rows에도 동일하게 초기값 추가
- 행 레이아웃 2행: `구분(1) | 통화(1) | 비용(인당)(1) | 비고(sm:2)`
  - 데스크탑(5col): 1+1+1+2 = 5 ✓, 모바일(2col): 2행으로 자연스럽게 wrap
- 통화: `Controller + FieldSelect` (h-7 text-sm)
- 비용(인당): `register + Input` (h-7 text-sm, placeholder "0")

**기존 항차 수정** (`ItineraryCard.tsx`)
- `FieldSelect` import 추가, `CURRENCY_OPTIONS` 동일하게 정의
- `DraftDay` 타입, `EMPTY`, `toDraft`, `toInput` 이미 `cost/cost_currency` 포함 (이전 세션에서 준비됨)
- 편집 모드 행 레이아웃 2행: `구분(col-span-2 sm:1) | 통화(2 sm:1) | 비용인당(2 sm:1) | 비고(2 sm:2)`
