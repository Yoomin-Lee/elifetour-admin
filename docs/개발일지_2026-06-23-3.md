## 1. 새 행사 등록 캐빈 등급 다중 추가 지원

### 배경
기존 `CabinPriceSection`은 단일 캐빈 등급만 입력 가능. 하나의 항차에 여러 등급(4D, 2D, BA2 등)을 등록하는 경우를 처리하지 못함.

### 스키마 변경 (`src/lib/schemas/voyage.ts`)

단일 필드 → 배열로 교체:

```ts
// 제거
cabin_grade:    z.string().optional()
cabin_ccf:      z.coerce.number().nullable().optional()
cabin_nccf:     z.coerce.number().nullable().optional()
cabin_tax:      z.coerce.number().nullable().optional()
cabin_tip:      z.coerce.number().nullable().optional()
cabin_currency: z.string().default('USD')

// 추가
export const cabinGradeItemSchema = z.object({
  grade:    z.string().default(''),
  total:    z.coerce.number().min(0).default(0),
  reserved: z.coerce.number().min(0).default(0),
  ccf:      z.coerce.number().nullable().optional(),
  nccf:     z.coerce.number().nullable().optional(),
  tax:      z.coerce.number().nullable().optional(),
  tip:      z.coerce.number().nullable().optional(),
  currency: z.string().default('USD'),
  agent:    z.string().optional(),
})

cabin_grades: z.array(cabinGradeItemSchema).default([])
```

### CabinPriceSection UI 재작성

`useFieldArray` 기반 다중 행 UI:

| 상태 | UI |
|------|-----|
| 빈 상태 | "등록된 캐빈 등급이 없습니다" + `+ 첫 등급 추가` CTA |
| 항목 있음 | 각 행에 🗑 삭제 버튼 |
| 카드 헤더 | `등급 추가` 버튼 항상 표시 |

**각 행 구조 (2행 레이아웃)**
- 1행: 캐빈 등급 · 보유 · 통화 · 🗑
- 2행 (구분선): CCF + NCCF + TAX + TIP = 캐빈가(실시간)

### createVoyageWithChildren 업데이트 (`src/lib/queries/voyages.ts`)

```ts
// 전: 단일 필드 처리
const { ..., cabin_grade, cabin_ccf, cabin_nccf, cabin_tax, cabin_tip, cabin_currency } = values
if (total > 0 || cabin_grade) {
  await saveCabinGrades(id, [{ grade: cabin_grade || '기본', ... }], [])
}

// 후: 배열 처리
const { ..., cabin_grades } = values
if (cabin_grades.length > 0) {
  await saveCabinGrades(id, cabin_grades.map((g, i) => ({
    grade: g.grade || '기본',
    total: g.total || 0,
    price_per_person: price || null,
    ccf: g.ccf ?? null, nccf: g.nccf ?? null,
    tax: g.tax ?? null, tip: g.tip ?? null,
    currency: g.currency || 'USD',
    agent: g.agent || null,
    sort_order: i,
  })), [])
}
```

## 2. 캐빈가 에이전트 드롭다운 + SelectOrInput 공유 컴포넌트

### 배경
`CruiseTab`의 캐빈 등급 편집에 이미 에이전트 `SelectOrInput`이 있었으나, 새 행사 등록 폼(`CabinPriceSection`)에는 없었음. 또한 `SelectOrInput`이 `CruiseTab` 내부에 로컬로 정의되어 재사용 불가.

### SelectOrInput 공유 컴포넌트 추출

`src/components/ui/select-or-input.tsx` 신규 생성.

- 드롭다운 목록 + `✏ 직접 입력` 옵션 포함
- 직접 입력 모드 전환 시 text input으로 교체
- 기존 DB 값이 목록에 없으면 동적으로 목록 상단에 추가
- `CruiseTab` 로컬 정의 제거 → 공유 컴포넌트 import로 교체

### CabinPriceSection 1행 레이아웃 변경

```
Before: [캐빈 등급] [보유] [통화] [🗑]
After:  [캐빈 등급] [보유] [에이전트] [통화] [🗑]
```

에이전트 목록: `TMK / COSTA / ONLINE / DONGBO / VASCO / FLORENCE` + 직접 입력

2행에 `border-t` 구분선 추가로 시각적 분리.
