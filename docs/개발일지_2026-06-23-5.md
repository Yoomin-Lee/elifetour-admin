### 1. 비용(인당) null vs 0 처리 수정

**파일**: `src/components/voyages/ItineraryEditor.tsx`

- `z.coerce.number()` 스키마가 빈 문자열 `""` → `0` 으로 강제 변환하는 문제
- `register` 대신 `Controller` 로 교체 후 `onChange` 직접 핸들링
  ```ts
  onChange={e => field.onChange(e.target.value === '' ? null : Number(e.target.value))}
  ```
- 결과: 입력 비워두면 `null` 저장, 숫자 입력하면 해당 숫자 저장 (0과 미입력 구분)

### 5. 기본정보 섹션 레이아웃 정비 (BasicInfoSection.tsx)

**목표**: 왼쪽 — 선사/크루즈 선박명, 오른쪽 — 항공사×2

**문제**: CSS Grid `sm:grid-cols-2` 자동 배치는 DOM 순서에 따름. 승선일(홀수 번째) 이후 다음 요소가 col 2(오른쪽)에 배치됨.

**해결**: DOM 순서 조정
```
승선일        | 항공사 wrapper (space-y-4) ← 오른쪽 ✓
선사/크루즈 wrapper (space-y-4) ← 왼쪽 ✓ | 인솔자
```
- 항공사 wrapper를 승선일 바로 다음(col 2)에 배치
- 선사/크루즈 wrapper를 그 다음(col 1)에 배치
