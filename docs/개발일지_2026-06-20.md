## 3. 크루즈 캐빈가 버그 수정 + 컬럼 위치 조정

### 버그
편집 폼에서 캐빈가를 입력해도 DB에 저장되지 않는 문제.

**원인**: `saveMut` 내부에서 `editForm.cabin_price`가 빈 문자열일 때 `Number('')` = `0` 으로 처리되어 `null` 체크가 되지 않아 기존 값을 `0`으로 덮어쓰는 버그.

```typescript
// 수정 전: Number(editForm.cabin_price) → 빈 문자열 → 0으로 저장
// 수정 후: editForm.cabin_price !== '' 조건 확인 후 처리
const priceToSave = editForm.cabin_price !== ''
  ? Number(editForm.cabin_price)
  : (existing?.price_per_person ?? null)
```

### 컬럼 위치
캐빈가 컬럼이 테이블 끝에서 잔여캐빈 바로 오른쪽으로 이동 → 캐빈 현황 한눈에 파악.

### 6-3. 현재 적용 구간 표시 (D-day 기반)

출발일 기준 D-day를 계산해 현재 날짜에 해당하는 취소료 구간을 앰버 배지로 강조 표시.

```typescript
function calcDMinus(departureDate?: string | null): number | null {
  if (!departureDate) return null
  const dep = new Date(departureDate + 'T00:00:00')
  const today = new Date(); today.setHours(0, 0, 0, 0)
  return Math.ceil((dep.getTime() - today.getTime()) / 86400000)
}

function isActivePolicyRow(
  start_d_minus: number | null,
  end_d_minus: number | null,
  d: number | null
): boolean {
  if (d === null || d < 0) return false
  const inStart = start_d_minus == null || d <= start_d_minus
  const inEnd   = end_d_minus   == null || d >= end_d_minus
  return inStart && inEnd
}
```

- 현재 적용 구간 행: 앰버 배경 강조
- "적용중" 배지: `<Zap />` 아이콘 + 앰버 컬러

## 7. history_logs UPDATE RLS 정책 추가

### 원인
히스토리 수정 버튼이 UI에 존재했으나 저장 시 403 에러 발생.  
`history_logs` 테이블에 SELECT/INSERT/DELETE 정책은 있었으나 **UPDATE 정책이 누락**.

### 마이그레이션
```sql
-- supabase/migrations/20260620010000_history_logs_update_policy.sql
CREATE POLICY "update history"
  ON history_logs
  FOR UPDATE
  USING (eli_get_my_role() IN ('admin', 'staff'))
  WITH CHECK (eli_get_my_role() IN ('admin', 'staff'));
```

수동 적용 후 히스토리 수정 정상 동작 확인.

## 8. 히스토리 탭 정렬 + textarea 자동 높이

### 정렬
히스토리 마스터 탭에서 가장 최신 행사가 상단에 오도록 클라이언트 정렬 추가.

```typescript
.sort((a, b) => {
  const depA = a.voyages?.departure_date ?? ''
  const depB = b.voyages?.departure_date ?? ''
  if (depB !== depA) return depB.localeCompare(depA)
  return b.logged_at.localeCompare(a.logged_at)
})
```

### textarea 자동 높이
히스토리 내용 수정 시 텍스트박스가 내용 길이에 맞게 자동으로 늘어나도록 처리.

```typescript
// useRef + useEffect 패턴 (callback ref 방식은 React 타이밍 이슈로 실패)
const editTextareaRef = useRef<HTMLTextAreaElement>(null)
useEffect(() => {
  const el = editTextareaRef.current
  if (!el) return
  el.style.height = 'auto'
  el.style.height = el.scrollHeight + 'px'
}, [editText, editingId])
```

**핵심**: inline callback ref (`ref={el => el && ...}`)는 React가 null → element 순서로 호출하는 타이밍 문제로 동작 불안정. `useRef` + `useEffect`(deps: editText, editingId) 조합이 올바른 패턴.

적용 파일: `HistoryTab.tsx`, `HistoryCard.tsx`
